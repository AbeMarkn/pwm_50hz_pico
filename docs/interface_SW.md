# ソフトウェア インターフェース設計

## 1. Module間API

### 1.1 `pwm_controller` Module

| 設計ID | API | 入力 | 戻り値 | 例外・副作用 |
| :--- | :--- | :--- | :--- | :--- |
| DESN-SW-004 | `read_switch_value(input_pins)` | GP1～GP4順の4入力オブジェクト | 0～15の整数 | 各入力を1回読み取る。読取り失敗は呼出元へ送出する。 |
| DESN-SW-004 | `duty_percent_for(value)` | 0～15の整数 | 0～100の整数 | 0～10は10倍、11～15は0。範囲外は`ValueError`。 |
| DESN-SW-004 | `blink_value(led, value, sleep_fn)` | LED出力、0～15、待機関数 | なし | 値の回数だけ点灯・消灯する。終了時は消灯。 |
| DESN-SW-004 | `apply_pwm(pwm, duty_percent)` | PWM、0～100の整数 | なし | 0～90%では50 Hzと16ビットデューティ値を設定する。100%は呼出元がPWMを停止してGP0を固定Highへ設定する。 |
| DESN-SW-003 | `run(pin_factory, pwm_factory, sleep_fn, hold_output)` | ハードウェア生成関数、待機関数およびPWM出力の保持指定。省略時はMicroPython APIを使用し、保持しない。 | PWMオブジェクト | 初期化成功後、LEDを0.5秒点灯して消灯し1秒待機する。続けて読取りと通知を実行し、通知完了後に1秒待機してからPWMを設定する。PWM設定後はLEDを点灯する。`hold_output`が真の場合は停止要求までPWMを保持し、停止時にPWMを0%へ戻してLEDを消灯する。 |
| DESN-SW-003 | `hold_pwm_output(sleep_fn)` | 待機関数。省略時はMicroPython APIを使用する。 | なし | 停止されるまで1秒ごとに待機し、呼出元が保持するPWMオブジェクトを有効に保つ。 |

API名と引数はv1.0.0で実装済みである。変更する場合は、仕様を変えない範囲でも設計文書を先に更新する。

## 2. データ構造

永続データおよび構造体は使用しない。処理中は次のスカラー値だけを保持する。

| 名称 | 型 | 範囲 | 用途 |
| :--- | :--- | :--- | :--- |
| `switch_value` | 整数 | 0～15 | 起動時に取得した4ビット設定値 |
| `duty_percent` | 整数 | 0～100 | 出力デューティ比 |
| `duty_u16` | 整数 | 0～65535 | MicroPython PWM APIへ渡す値 |

## 3. イベントとコールバック

| 種別 | 使用 | 内容 |
| :--- | :---: | :--- |
| 起動イベント | 使用 | `main.py`の実行を契機に初期処理を開始する。初期化成功後、LEDを0.5秒点灯して消灯し1秒待機してから、DIPの読取りと点滅通知を行う。 |
| DIP変更イベント | 不使用 | 起動後の変更を検出しない仕様のため。 |
| PWM周期イベント | ユーザーコードでは不使用 | ハードウェアPWM周辺回路が自律生成する。 |
| コールバック | 本番コードでは不使用 | 単体テストでは端子生成関数と待機関数を注入する。 |

## 4. Task間通信と同期

OSおよび並行Taskを使用しないため、Queue、Mutex、Semaphore、Shared Memoryはすべて使用しない。割込サービスルーチンも実装しない。処理は単一フローであり、共有データ競合は発生しない。

## 5. エラー伝達

- 設定値11～15は例外ではなく、仕様で定義された異常設定として0%へ変換する。
- API契約外の値およびハードウェアAPI失敗は例外として呼出元へ伝達する。
- 最上位処理は可能な範囲でPWMを0%、LEDを消灯してから例外を再送出し、開発時にREPLで原因を確認可能にする。
- Watchdogによる自動復旧は行わない。
- 試作品のため永続ログおよび保守用インターフェースは設けない。

# 仕様テスト（正常系）

## 1. 方針

- 内部実装を前提としないブラックボックステストとする。
- 実機なし自動テスト、実機あり自動テスト、実機あり手動テストの順で実施する。
- 結果は本書へ記入せず、`results/TEST-SPEC_result_template.md`を基に実施回ごとの連番ファイルへ記録する。
- PWM周波数はオシロスコープ、LED回数と周期は目視で確認する。

## 2. 実機なし・自動

### TEST-SPEC-001 有効設定値と出力の対応

| 項目 | 内容 |
| :--- | :--- |
| 関連ID | SPEC-F-001、SPEC-F-003、SPEC-F-005 |
| 区分 | 正常系、境界値、実機なし、自動 |
| 事前条件 | 外部から4入力、時刻、LED状態、PWM設定値を観測・操作できるシミュレーション環境 |
| 手順 | 1. 設定値0～10を1値ずつ与えて起動する。2. LED通知完了まで進める。3. 出力値を取得する。 |

## 3. 実機あり・自動

### TEST-SPEC-003 PWM正常出力

| 項目 | 内容 |
| :--- | :--- |
| 関連ID | SPEC-F-003、SPEC-F-005、SPEC-NF-001 |
| 区分 | 正常系、境界値、実機あり、自動 |
| 試験設備 | DIP制御治具、周波数・デューティ比を自動取得できる測定器 |
| 手順 | 1. 設定値0～10を順に設定して各回電源を再投入する。2. LED通知完了後のGP0を測定する。3. 60秒後にも再測定する。 |

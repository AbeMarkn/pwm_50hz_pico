# 設計テスト（正常系）

## 1. 方針

- Module、API、状態遷移、初期処理およびハードウェア設定をホワイトボックスで確認する。
- 実機なし自動テストを先に行い、その後に実機あり自動・手動テストを行う。
- 結果は`results/TEST-DESN_result_template.md`を基に実施回ごとの連番ファイルへ記録する。

## 2. 実機なし・自動

### TEST-DESN-001 4ビット入力変換

| 項目 | 内容 |
| :--- | :--- |
| 関連ID | DESN-SW-004 |
| 手順 | 16通りの入力レベルをテストダブルで与え、`read_switch_value`を実行する。 |
| 期待値 | ON=LowとしてGP1/GP2/GP3/GP4を重み1/2/4/8へ変換し、0～15を返す。各端子は1回だけ読み取られる。 |
| カバレッジ | 対象ModuleのC0 100%、入力論理分岐のC1 100%を目標とする。 |

### TEST-DESN-002 デューティ変換

| 項目 | 内容 |
| :--- | :--- |
| 関連ID | DESN-SW-004 |
| 手順 | 0～15を`duty_percent_for`へ与え、戻り値を確認する。0～100%を10%刻みで`apply_pwm`へ与える。 |
| 期待値 | 0～10は値×10%、11～15は0%。PWMには周波数50 Hzと、丸め式に一致する0～65535が設定される。 |
| カバレッジ | 正常・異常設定分岐のC1 100%を目標とする。 |

### TEST-DESN-003 LED通知API

| 項目 | 内容 |
| :--- | :--- |

| 手順 | 0～15を`blink_value`へ与え、LEDおよび待機関数の呼出履歴を取得する。 |
| 期待値 | 値と同じ回数の点灯・消灯があり、各待機引数は0.25秒、終了時は消灯である。0では待機しない。 |

### TEST-DESN-004 起動シーケンス

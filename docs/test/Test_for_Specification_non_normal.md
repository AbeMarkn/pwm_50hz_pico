## 4. 適用性を評価した項目

| 観点 | 扱い |
| :--- | :--- |
| センサー異常 | センサーを使用しないため対象外。DIPは起動時に1回だけ読み、チャタリング対策を要求しない。 |
| 通信断 | 運用時通信を使用しないため対象外。 |
| メモリ不足 | 外部ブラックボックスから再現条件を保証できないため設計テストで扱う。 |
| ストレージ異常 | 運用データを保存しない。ファームウェア破損時の起動不能はMicroPython基盤の範囲とする。 |
| Watchdog | 使用しないため、Watchdog自体の異常試験は対象外。 |

## 2. 分類

### 2.1 確定事項

- 電源投入時に4個のディップスイッチから設定値を取得する。
- 内蔵表示灯、ディップスイッチ入力およびPWM出力の初期化が成功した後、内蔵表示灯を0.5秒点灯して消灯し、1秒待機する。
- 起動表示の待機後、設定値を内蔵表示灯の点滅回数で通知する。点滅通知の完了後は1秒待機してからPWM出力を開始する。
- PWM出力中は内蔵表示灯を点灯状態に維持し、PWM出力を終了するときは内蔵表示灯を消灯する。
- PWMの基本周波数は50 Hzとする。
- 有効な設定値は0～10で、デューティ比0～100%へ10%刻みで対応させる。
- 設定値11～15は異常値とする。
- 異常値の場合も設定値と同じ回数だけ点滅し、その後の出力を0%に固定する。
- 設定値は起動時にだけ取得し、動作中のスイッチ変更は次回の電源再投入まで反映しない。
- 点滅1周期は0.5秒とする。

### 2.2 制約事項

- 使用するマイコンボードおよびソフトウェア実行環境は指定済みである。具体名は設計書に記載する。
- 出力端子および入力端子は指定済みである。具体的な端子番号はハードウェアインターフェース仕様に記載する。

### 2.3 仮定・設計提案

仕様へ追加する仮定および設計提案はない。実装上必要な提案は設計書、未確定事項は `open_item.md` に記載する。

## 3. 機能仕様

| ID | 機能仕様 |
| :--- | :--- |
| SPEC-F-001 | 利用者が装置の電源を投入すると、装置は4個のディップスイッチから設定値を1回取得する。動作中のスイッチ変更は出力へ反映せず、次回の電源再投入時に反映する。 |
| SPEC-F-002 | 内蔵表示灯、4個のディップスイッチ入力およびPWM出力の初期化に成功した後、装置は内蔵表示灯を0.5秒点灯して消灯し、1秒待機する。 |
| SPEC-F-003 | 起動表示の待機後、装置は取得した設定値と同じ回数だけ内蔵表示灯を点滅させる。設定値0の場合は点滅しない。点滅通知の完了後、装置は1秒待機してからPWM出力を開始する。 |
| SPEC-F-004 | 設定値が0～9の場合、装置は表示灯による通知の完了後、設定値に10%を乗じたデューティ比のPWMを出力する。設定値10の場合は、GP0を3.3 V系の固定High出力とする。 |
| SPEC-F-005 | 設定値が11～15の場合、装置は設定値と同じ回数だけ表示灯を点滅させた後、出力を0%に固定する。 |
| SPEC-F-006 | PWMの出力設定後、装置は内蔵表示灯を点灯状態にし、次の電源断、再起動または停止要求まで、起動時に決定したPWM出力を維持する。停止要求を受けた場合、装置はPWM出力を0%にして内蔵表示灯を消灯する。 |

## 4. 非機能仕様

| ID | 分類 | 非機能仕様 |
| :--- | :--- | :--- |
| SPEC-NF-001 | 性能 | PWMの基本周波数は50 Hzとし、オシロスコープで公称値を確認する。数値による許容誤差は規定しない。 |
| SPEC-NF-002 | 性能 | 表示灯の点滅は、点灯時間と消灯時間を合わせて1周期0.5秒とし、回数と周期を目視で確認する。数値による許容誤差は規定しない。 |
| SPEC-NF-003 | 信頼性 | 異常設定値11～15を検出した場合、出力を0%とする安全側の動作を維持する。 |
| SPEC-NF-004 | 電源断時 | 電源断後に出力信号が維持されることを要求しない。再投入時は設定値の取得から処理を開始する。 |
| SPEC-NF-005 | 電源 | USB給電で動作する。電池および充電機能は使用しない。 |
| SPEC-NF-006 | 信頼性 | 試作品のためWatchdogによる自動復旧を要求しない。 |
| SPEC-NF-007 | 環境 | 屋内で使用する。温度・湿度・結露の定量条件は規定せず、部品条件は実機確認後に必要に応じて検討する。 |
| SPEC-NF-008 | 保守性 | 試作品のため永続ログおよび保守機能を要求しない。 |
| SPEC-NF-009 | 安全性 | 試作品の動作確認を優先し、過電圧、過電流、逆接およびバッテリーに対する追加保護回路を要求しない。 |
| SPEC-NF-010 | 制約 | サイズ、重量およびコストに追加制約を設けず、マイコンボード単体規模を許容する。 |
| SPEC-NF-011 | 信頼性 | 最大連続運転時間は24時間とする。 |
| SPEC-NF-012 | 接続制約 | PWM出力にはオシロスコープ等の計測機器だけを接続し、モータ等の負荷を接続しない。 |

## 5. 要求を設けない項目

次の項目は試作品として要求を設けないことが決定済みである。

| 分類 | 決定内容 |
| :--- | :--- |
| 性能 | 電源投入から入力読取りおよび出力開始までの時間を規定しない。入力安定待ち時間を設けない。 |
| 信頼性 | Watchdog、自動復旧を設けない。最大24時間を超える連続運転を要求しない。 |
| 環境 | 屋内使用とし、温度・湿度・結露の定量範囲を規定しない。 |
| 保守性 | 永続ログ、現場保守機能および長期保守運用を設けない。 |
| 安全性 | 追加の電気保護回路を設けない。USB給電元および計測器は各機器の定格内で使用する。 |
| 制約 | マイコンボード以外のサイズ、重量、ケースおよび目標コストを規定しない。 |

## 6. 受入れの考え方

- 各機能仕様は外部操作と出力波形または表示灯の観察によって確認する。
- PWM周波数はオシロスコープ、LED通知は目視で公称動作を確認する。
- 仕様と設計およびテストの対応は、テスト文書内のトレーサビリティマトリクスで管理する。
